# B站直播间定时发随机弹幕（悬浮维护版）

基于 [Gamyou 原版](https://github.com/Gamyou/bilibili-live-random-send) 的维护分支，由 Yuiffy 维护，保留 Apache-2.0 许可证。这是独立维护的 Fork，与原作者的浏览器扩展分开发布。

## 安装

推荐从 [Greasy Fork 发布页](https://greasyfork.org/zh-CN/scripts/606129) 安装并接收后续更新。

也可先安装 Tampermonkey 等用户脚本管理器，再打开 [完整脚本安装链接](https://raw.githubusercontent.com/Yuiffy/bilibili-live-random-send/master/dist/bilibili-live-random-send.user.js)。也可从 [Releases](https://github.com/Yuiffy/bilibili-live-random-send/releases/latest) 下载 `.user.js`。

已有原版或此前修复版的用户：先备份脚本与配置，再进入**现有脚本的编辑器**，用新版本完整代码替换并保存，可继续读取该脚本已有的房间配置。安装为另一个脚本不会自动共享旧脚本的存储；不要同时启用两个版本，以免重复发送或点赞。

## 使用

打开 B 站数字房间号的直播页，右侧会出现「弹幕／开始／设置」悬浮工具。拖动「弹幕」调整位置，双击恢复右下角默认位置。位置按最近的横向、纵向边缘保存间距，缩放窗口或切换最大化时会跟随对应角落；缩小时暂时限制在窗口内，放大后恢复原间距。悬浮入口挂在页面根部，不依赖「实验室」「关注」或旧弹幕操作栏。

- 设置弹幕分组，多条文字使用 `|` 分隔；支持随机或顺序发送、共用弹幕源及零点打卡。
- 点击「开始」立即尝试发送第一条，再按设置间隔发送；点击「停止」结束。输入框中有手动草稿时跳过当次发送。
- 自动点赞可选随机间隔（每次 3～15 秒）或固定间隔（至少 3 秒）；设置面板提供倒计时和「测试点赞一次」。
- 修改后点击底部「保存」；关闭或按 Esc 会恢复上次保存的设置。房间设置独立保存，原版的直播间简化选项仍保留。

点赞状态中的次数表示脚本触发的 DOM 点击次数，不能证明 B 站服务端已经计入。浏览器后台节流、登录状态、B 站限制及后续页面改版仍可能影响实际执行；「防休眠」也不能保证后台计时精度。

从 3.0.0 升级会将旧坐标转成边缘间距。旧记录没有保存窗口尺寸，若按钮升级前已经偏到中间，双击「弹幕」一次即可重新固定在右下角。

## 相对原版的变化

3.0.0 将原版模块与修复逻辑整理为可读源码，完整打包到单个脚本中，不再下载、缓存或动态执行远程功能模块。移除过时的按钮挂载逻辑，修复随机点赞调度和按钮定位，并增加缺失输入框保护及配置迁移测试。

源码在 `src/`，发布文件在 `dist/`，旧 `prod/` 入口已移除。上游提供的是压缩模块；`src/runtime.js` 在保留出处的前提下经一次 AST 整理恢复为维护源码。原版说明保存在 [docs/UPSTREAM.md](docs/UPSTREAM.md)。

## 开发与验证

使用 Node.js 24 或更高版本：

```sh
npm ci
npm run check
```

检查会构建完整发布脚本、运行 jsdom 回归测试、检查 JavaScript 语法及自包含发布要求。构建不压缩、不混淆，无生产环境 npm 依赖。修改源码后应提交同步生成的 `dist/` 文件。

测试在隔离的页面中模拟点击与时间，不向实际直播间发送弹幕或点赞。原版的所有简化及抽奖功能未逐项进行真实登录环境验证。
