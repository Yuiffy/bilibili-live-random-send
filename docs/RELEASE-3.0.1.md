修复窗口改变大小后，悬浮工具偏到中间的问题。

- 拖动后按最近边缘记住间距，最大化或缩小窗口时跟随对应角落。
- 窗口太小时暂时将工具限制在可见区域，放大后恢复原间距。
- 默认及双击复位位置为右下角；自动迁移 3.0.0 的旧位置记录。
- 如果升级前按钮已经偏到中间，双击「弹幕」一次即可归位。旧记录未存窗口尺寸，无法恢复早先窗口中的精确边距。
