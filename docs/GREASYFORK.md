# B站直播间定时发随机弹幕（悬浮维护版）

这是基于 [Gamyou 原版](https://greasyfork.org/zh-CN/scripts/446725) 的独立维护分支，遵循 Apache-2.0 许可，并保留原作者署名。

## 维护内容

- 右侧可拖动的「弹幕／开始／设置」悬浮工具，双击拖动条恢复默认位置；设置面板挂在页面根部，不再依赖旧版弹幕栏。
- 修复随机时间点赞：每次独立随机等待 3～15 秒；固定间隔至少 3 秒，切换或停止会取消旧任务。
- 优先定位直播间点赞按钮，排除隐藏按钮和主播动态点赞；提供倒计时、点击次数和手动测试。
- 保留弹幕分组、随机或顺序定时发送、共用弹幕源、零点打卡及原版直播间简化选项。
- 所有功能代码随脚本完整发布，不再下载或动态执行远程功能模块。

## 使用与升级

安装后打开 B 站数字房间号直播页。弹幕用 `|` 分隔，修改后点击面板底部「保存」。点击「开始」会立即尝试发送第一条；手动输入框有草稿时跳过本轮。

如果需要保留原版或此前修复版的配置，请先备份，再进入**原有脚本的编辑器**，完整替换代码并保存；作为新脚本安装不会自动共享旧脚本的存储。不要同时启用两个版本。

点赞次数只表示触发点击，不能证明服务端计入。后台节流、未登录、站点限制及后续改版仍可能影响执行。原版简化及抽奖选项保留，但没有逐项完成真实登录环境验证。

源代码、更新记录与问题反馈：[GitHub 仓库](https://github.com/Yuiffy/bilibili-live-random-send)。
